# 磁力功能与顶部按钮设计

## 目标

修复双布局无线通用终端安装并启用磁力卡后，AE2WTLib 仍可能读取其他无线合成终端缓存、导致磁力不工作的情况；同时将磁力过滤按钮从左侧导航栏移到搜索框左侧。

## 行为设计

- `CraftingTerminalHandler` 第一次为新打开的双布局 `WideUniversalMenu` 查找终端时，刷新其查找缓存。
- 刷新后，AE2WTLib 下一次处理磁力功能时会按其原生优先级重新查找终端，并优先选择物品栏或饰品栏中的无线通用终端。
- 不替换 AE2WTLib 的磁力吸取、过滤、直接拾取至 ME 网络等实现，也不改变其他终端的菜单和 tick 行为。

## 界面设计

- 删除 `addToLeftToolbar` 中的磁力按钮。
- 使用 AE2WTLib 原生 16×16 按钮背景和磁力图标。
- 固定在搜索框左侧：`left = 223`、`top = 2`。按钮右缘为 239，搜索框从 241 开始，中间保留 2 像素。
- 仅安装磁力卡时显示；提示文字和点击后打开原生磁力过滤菜单的行为保持不变。

## 验证

- 回归测试读取最终样式，验证磁力按钮尺寸、位置以及与搜索框的 2 像素间距。
- 回归测试验证缓存 Mixin 同时清除终端定位器和磁力宿主，并且仅识别双布局通用终端菜单。
- 编译全部 Java 源码并检查最终 JAR 内的类、Mixin 配置、样式和版本号。
