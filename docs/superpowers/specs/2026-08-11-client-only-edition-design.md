# AE2 Wide Wireless Terminal 纯客户端版设计

日期：2026-08-11

## 目标

在 `client-only` 分支提供一个仅客户端安装的 NeoForge 1.21.1 版本。服务器无需安装本 Mod，客户端仍可获得受支持终端的 18 列宽屏、宽窄切换、物品/流体筛选按钮，以及天枢和 EAEP 的界面布局兼容。

## 边界

纯客户端版不注册菜单，不增加容器槽位，不替换服务端打开逻辑，也不发送本 Mod 自定义的菜单操作。无线通用终端恢复 AE2WTLib 原生的当前终端界面，因此不再提供完整版的合成与样板编码双工作区、双区域 JEI 拉取、磁力缓存刷新和自定义垃圾桶入口。

其他终端继续使用已有的客户端宽屏资源和 Mixin。AE2WTLib 的无线通用终端仍保持固定宽度，不显示本 Mod 的宽窄按钮；无线合成终端、无线样板编码终端和其他受支持终端保留原有宽窄功能。

## 实现

- Mod 入口限定为 `Dist.CLIENT`，不注册 `MenuType` 或菜单屏幕。
- 公共 Mixin 列表为空，只保留客户端界面 Mixin。
- 删除双布局菜单、菜单宿主、双布局屏幕、JEI 双目标处理器和相关资源。
- 清除保留的布局 Mixin 中对 `WideUniversalScreen` 的特殊分支。
- NeoForge、Minecraft、AE2 和 AE2WTLib 依赖均标记为客户端依赖。
- 版本使用 `2.1.22-client.1`，构建文件名不含 `final`。

## 发布与兼容

客户端版和完整版使用相同 Mod ID，不能同时安装。完整版继续保留在 `main` 分支；本次修改只提交并推送 `client-only` 分支。

完成标准是源码边界测试、布局回归测试和干净 Gradle 构建全部通过，并对最终 JAR 做条目与元数据审计。
