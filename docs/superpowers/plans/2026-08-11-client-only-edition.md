# AE2 Wide Wireless Terminal 纯客户端版实现计划

日期：2026-08-11

1. 添加纯客户端分发测试，先证明现有完整版代码不满足边界。
2. 将 Mod 入口限制到客户端，移除菜单注册、服务端逻辑和双布局专用实现。
3. 清理客户端 Mixin 配置及剩余布局分支，保留普通终端、无线终端、EAEP 和天枢兼容。

5. 重构现有回归测试，使其验证客户端版仍保留的功能，并修正 CRLF 行尾兼容。
6. 执行 `gradlew clean build`，随后运行全部适用测试和最终 JAR 审计。
7. 提交到 `client-only` 并推送同名远程分支，不合并 `main`。
